# 001 · Preparar CONVENCIONES.md y evaluar la VPS

**Pedido del usuario (verbatim):**

> «Deja preparado el CONVENCIONES.md del repo, y si puedes tocar VPS»

**Interpretación acordada:**

1. Crear `CONVENCIONES.md` en el repo `tarea_2_curso_2` (estándar del grupo: encabezado de archivos,
   registro de prompts `prompt_NNN`/`salida_NNN`, commits, idioma/zona horaria).
2. «Tocar la VPS» = ejecutar el **paso 1** del prompt inicial (`prompt_000.md`, §16): **evaluar los
   recursos de la VPS** (RAM, disco, puertos, servicios) para decir **si cabe** la Tarea 2 y proponer
   puertos/servicios. **Solo lectura, sin crear ni desplegar nada**, conforme a la restricción dura del
   prompt inicial.

**Restricción aplicada:** no se ejecuta ningún cambio con efecto en el servidor (nada de `sudo`, nada de
crear servicios ni desplegar). Las acciones que requieran `sudo` se **proponen** para que las ejecute el
usuario con el usuario `administrator`.
